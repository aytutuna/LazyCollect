# Page photos

Three frames of the SmartDoc 2015 Challenge 1 dataset (https://github.com/jchazalon/smartdoc15-ch1-dataset, release v2.0.0),
scaled to 1280 x 720 and saved as JPEG at quality 90, with the page's corners in `corners.json` (pixels of these files,
named by the page's own top). Used by the scanner checks (`npm run detect`) and the accessibility states.

The dataset is licensed under Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/).
These files are changed from the original: scaled down and re-encoded.

Jean-Christophe Burie, Joseph Chazalon, Mickael Coustaty, Sebastien Eskenazi, Muhammad Muzzamil Luqman, Maroua Mehri,
Nibal Nayef, Jean-Marc Ogier, Sophea Prum and Marcal Rusinol: "ICDAR2015 Competition on Smartphone Document Capture
and OCR (SmartDoc)", 13th International Conference on Document Analysis and Recognition (ICDAR), 2015.
